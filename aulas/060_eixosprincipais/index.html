1. Rotação dos Eixos e Equações de Transformação

Dedução Cinemático-Geométrica

Considere a rotação de um par ortogonal cartesiano original $(x, y)$ para um novo sistema $(x', y')$ rotacionado por um ângulo positivo $\theta$ (anti-horário) em relação à origem $O$.

• Transformação de Coordenadas de um Elemento $dA$:

$x' = x \cos\theta + y \sin\theta$

$y' = -x \sin\theta + y \cos\theta$

As coordenadas do elemento $dA$ transformam-se ortogonalmente, servindo de base para o cálculo dos momentos integrais.

Integrais de Inércia no Sistema Rotacionado

Momento de Inércia $I_{x'}$:

$I_{x'} = \int_A (y')^2 dA = \int_A (-x\sin\theta + y\cos\theta)^2 dA$

Momento de Inércia $I_{y'}$:

$I_{y'} = \int_A (x')^2 dA = \int_A (x\cos\theta + y\sin\theta)^2 dA$

Produto de Inércia $I_{x'y'}$:

$I_{x'y'} = \int_A x' y' dA = (I_x - I_y) \sin\theta \cos\theta + I_{xy} (\cos^2\theta - \sin^2\theta)$

Formulação Final (Arcos Duplos $2\theta$):

$I_{x'} = \frac{I_x + I_y}{2} + \frac{I_x - I_y}{2}\cos 2\theta - I_{xy}\sin 2\theta$

$I_{y'} = \frac{I_x + I_y}{2} - \frac{I_x - I_y}{2}\cos 2\theta + I_{xy}\sin 2\theta$

$I_{x'y'} = \frac{I_x - I_y}{2}\sin 2\theta + I_{xy}\cos 2\theta$

2. Círculo de Mohr para Momentos de Inércia

Representação Gráfica

Proposto em 1882 por Christian Otto Mohr, o método gráfico transforma as equações paramétricas de rotação em uma circunferência no plano $(I_{x'}, I_{x'y'})$.

• Isolando os termos de $2\theta$:

$I_{x'} - \frac{I_x + I_y}{2} = \frac{I_x - I_y}{2}\cos 2\theta - I_{xy}\sin 2\theta$

$I_{x'y'} = \frac{I_x - I_y}{2}\sin 2\theta + I_{xy}\cos 2\theta$

Eleva-se ambas as equações ao quadrado e soma-se os termos para eliminar a variável angular $\theta$.

Equação Fundamental do Círculo

$\left(I_{x'} - \frac{I_x + I_y}{2}\right)^2 + (I_{x'y'})^2 = \left(\frac{I_x - I_y}{2}\right)^2 + I_{xy}^2$

Forma canônica $(X - a)^2 + Y^2 = R^2$ no plano cartesiano $X = I_{x'}$ e $Y = I_{x'y'}$.

Centro do Círculo ($C$):

$C = \left(\frac{I_x + I_y}{2}, 0\right)$

Raio do Círculo ($R$):

$R = \sqrt{\left(\frac{I_x - I_y}{2}\right)^2 + I_{xy}^2}$

Momentos Principais e Ângulos de Inércia:

$I_{max, min} = C \pm R = \frac{I_x + I_y}{2} \pm \sqrt{\left(\frac{I_x - I_y}{2}\right)^2 + I_{xy}^2}$

$\tan 2\theta_p = \frac{-2 I_{xy}}{I_x - I_y} \implies \theta_p = \frac{1}{2}\arctan\left(\frac{-2 I_{xy}}{I_x - I_y}\right)$
